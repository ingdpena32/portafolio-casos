# ERP interno — CEMA LTDA

**Rol:** Desarrollador de Software · 2024–2025
**Stack:** PHP · MySQL

## Contexto

Los procesos administrativos internos de la compañía se manejaban de forma manual y dispersa, dificultando la centralización de la información.

## Qué hice

• Desarrollé un sistema ERP para la gestión de procesos administrativos internos.

• Diseñé módulos para centralizar información y reducir procesos manuales.

• Di mantenimiento y corrección de errores según las necesidades operativas.

## Resultado

Reducción de procesos manuales mediante la centralización de información en un solo sistema.

*Por confidencialidad, no se incluye código fuente ni datos de la compañía.*
