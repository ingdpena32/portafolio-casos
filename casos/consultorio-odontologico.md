# Sistema de gestión — Consultorio odontológico

**Rol:** Desarrollador Full Stack · 2026
**Stack:** PHP · MySQL · HTML · CSS · JavaScript

## Contexto

El consultorio necesitaba centralizar la gestión de pacientes, historias clínicas, citas y pagos, que hasta entonces se manejaban de forma dispersa.

## Qué hice

• Desarrollé el sistema completo de gestión (pacientes, historias clínicas, citas, pagos).

• Diseñé la base de datos relacional, cuidando la integridad y consistencia de la información clínica y financiera.

• Implementé los módulos de agenda, citas y control de pagos aplicando las reglas de negocio del consultorio.

• Participé en la migración y puesta en producción del sistema.

## Resultado

Sistema en producción, actualmente en uso para la operación diaria del consultorio.

*Por confidencialidad, no se incluye código fuente ni datos del cliente.*
